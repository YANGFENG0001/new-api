# 用户管控：策略、策略池与应用绑定

## 职责与入口

入口：系统设置 → 安全与限制 → 用户管控。

- **策略**只定义限制和行为。直接绑定到名单、订阅或用户后全天生效。
- **策略池**只管理时间窗口、连续随机时间段、概率和现有策略引用，不复制策略行为，不允许嵌套策略池。
- **应用设置**决定名单、订阅或个人应用哪些策略／策略池，允许多选。名单的成员管理与绑定配置分开。
- **个人设置**替代旧的内联“用户覆盖”编辑器。默认合并继承的限制；具备放宽权限才能选择替代继承。替代必须有原因和至少一个绑定对象，可以设置到期时间。

默认管理权限及下放机制沿用现有用户管控权限配置。接口校验权限，不依赖界面隐藏。

## 时间与概率

1. 先查策略池是否启用、是否在有效时间窗口内。未命中窗口时不贡献行为。
2. 在每个连续时间段内，按策略池概率确定是否生效。
3. 池命中后，按成员的条件概率选择一个策略；成员概率必须合计 100%，支持两位小数和一键均分。
4. 同一个用户／策略池版本／窗口／连续时间段内保持选择不变，不随每个请求重抽。不同用户独立抽样；修改策略池版本会重新确定抽样序列。

例如池概率为 60%，两个成员分别为 25%、75%，其联合命中概率分别为 15%、45%；剩余 40% 不执行该池。其他直接绑定的策略、其他池或原有账号／令牌权限仍可能有效。

- 连续时间段可设置随机最短／最长分钟数（1～1440 分钟）；生效和未生效的结果均保持至该段结束。
- 支持多个自定义日期／星期／跨午夜窗口，独立时区和窗口概率／时长覆盖。
- 重叠窗口取最高优先级，再按窗口标识排序选一个，避免重复执行。
- 跨午夜窗口以开始日期为准；全天池不在午夜重抽。
- 成员被禁用后，其概率不会分摊给其他成员；命中该成员时不执行行为，并保留管理员判定记录。
- 同一纯行为策略在直接绑定与多个池中重复命中时，限定规则按策略标识去重，共享该用户的规则计数桶，不重复拼接提示词。
- 时段结束即停止贡献新请求的行为；已经开始的请求保持原有决策，不能据此强制中断已建立连接。

实现使用整数基点（10000 = 100%）、稳定种子和连续分段，解析结果短缓存最多 15 秒，跨分钟不复用。配置变更沿用现有缓存失效机制。

## 旧配置迁移与回退

本次迁移为**兼容运行＋显式切换**，不会自动拆解复杂的旧版重叠时间规则，也不会静默删除旧配置。

1. 升级前备份数据库。新增独立策略池表、应用绑定表及策略版本字段。
2. 未迁移的旧名单、订阅绑定、个人覆盖和旧版随机池继续按原逻辑执行。旧版定时策略在“旧版配置”页只读展示。
3. 创建新的纯行为策略及策略池，在名单／订阅／个人应用窗口检查旧配置预览，明确确认后保存。
4. 新绑定按拥有者独立切换，旧记录保留但不再双重执行。管理员可逐个迁移，不要求一次迁完全部用户。
5. 超级管理员可“恢复旧版绑定”。回退恢复保留的绑定记录；引用的共享策略使用其当前内容，**不是不可变的历史策略快照**。回退也推进版本号，拒绝陈旧编辑与重试覆盖。

个人设置到期后恢复名单／订阅继承，不重新激活已经被替换的旧个人覆盖。清空个人绑定也恢复继承。

“替代继承”会移除继承管控，即使其选中的池处于未命中时段也如此；界面明确提示此效果。它不绕过账号状态、API 密钥权限等基础授权。

批量应用支持追加、移除指定绑定及替换绑定列表，分别展示每位用户结果；重试仅提交失败用户。存在未迁移的个人旧配置时，追加／移除会拒绝操作，须先单独预览并迁移，避免无意删除原有限制。

## 资源选择与安全

模型、渠道、渠道类型、分组从本地数据库元数据生成可搜索选项，不向上游发起模型探测。模型允许补充别名；渠道不允许随意创造 ID。已经失效的引用保留并提示，不悄悄转换为“无限制”。资源目录当前一次载入、客户端搜索，尚未实现服务端分页。

新接口沿用 `user_control.read`、策略编辑、名单编辑、个人编辑及放宽权限。用户目标继续禁止自我管控、越级管控及管控超级管理员；回退仅限超级管理员。渠道查询明确选择元数据列，不查询或返回密钥。

应用绑定和策略池编辑使用版本校验。管理员审计记录包含拥有者、配置版本、目标、迁移确认及池决策；不会为此次重构伪造 token、费用或实际请求结果。

授权设计参考 OWASP Authorization Cheat Sheet 的默认拒绝、每次请求校验和对象级权限原则：
https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html

本次不变更登录／会话机制，不宣称完整 ASVS 合规。
